# RGB-D 重建论文与本项目的实施顺序

调研日期：2026-11-14。下述论文方法尚未作为完整算法集成本项目；本次实现的是 Quest 精修版本回传。

## 当前瓶颈

实时路径采用固定 96³ TSDF。50 cm 扫描盒对应约 5.2 mm 体素；减少体素尺寸并不能消除位姿误差和深度噪声。当前离线主路径以实时模型为初始几何，运行 OpenMVS 光度精修和贴图；尚无全局 RGB-D 位姿优化及修正后重融合。RGB 和深度的时间、外参一致性应先测量，不能从模型破碎直接断定唯一原因。

Quest 本次收到约 12000 面的面颜色预览，不等同于 PC 完整 UV 纹理模型。评价几何、照片贴图与 Quest 预览颜色时必须分别比较。

## 优先采用的研究方向

1. **BundleFusion (TOG 2017)**：稀疏特征与稠密几何/光度约束共同优化历史相机位姿，随后重新融合表面。最适合借鉴其“位姿修正 → 重融合”的结构，处理重影、厚层和碎片；无需声称已移植其原始实时系统。
   https://vcai.mpi-inf.mpg.de/projects/MZ/Papers/arXiv2016_BF/page.html
2. **Color Map Optimization (SIGGRAPH 2014, Zhou/Koltun)**：联合优化照片相机位姿及非刚性图像校正，改善多图贴图错位。Open3D 提供实现；适合作为 CPU 上的离线对比实验。图像形变不能作为真实几何正确性的证据。
   https://vladlen.info/publications/color-map-optimization-for-3d-reconstruction-with-consumer-depth-cameras/
   https://www.open3d.org/docs/latest/tutorial/pipelines/color_map_optimization.html
3. **Texture Mapping for 3D Reconstruction With RGB-D Sensor (CVPR 2018)**：选帧、视角/法线/投影面积评分、纹理块对齐，适合改进模糊照片过滤和局部选图，避免所有照片简单平均。
   https://openaccess.thecvf.com/content_cvpr_2018/papers/Fu_Texture_Mapping_for_CVPR_2018_paper.pdf
4. **GO-Surf (3DV 2022)**：RGB-D 监督的神经 SDF 与颜色联合优化，适合更慢的最终表面优化实验。官方实现测试环境为 CUDA 11.3，需要额外采样算子；目前 AMD RX 7800 XT 的 Windows 环境不能直接视为兼容。
   https://github.com/JingwenWang95/go-surf
5. **2D Gaussian Splatting (SIGGRAPH 2024)**：以定向二维表面元素表示场景并约束几何，可提取网格，适合照片外观和表面质量研究。官方加速实现有 CUDA 扩展，现有 AMD 环境需另行验证或移植，不能直接承诺可运行；也不能把新视角渲染效果当成尺寸准确性。
   https://github.com/hbb1/2d-gaussian-splatting

## 建议实验

先固定一组原始帧与留出视角。测量深度重投影误差、RGB 重投影误差、时间偏差；排除深度边缘不一致及模糊帧。用 Quest 位姿作为初值，加入保守的 RGB-D 位姿图优化，保留世界坐标锚定，再以优化后的位姿重建 TSDF。通过留出照片误差、深度误差、主连通分量与碎片数比较原始、重融合、光度精修结果；三角面数量和肉眼平滑度不作为单独质量指标。

贴图分支优先比较清晰度加权选图、遮挡检测、相机位姿色彩优化。保持原始照片不变，不将生成式补细节图片当作几何观测。深度置信度低或未观测的区域保留可识别状态。

## 本次回传协议

Quest 查询 `/api/sessions/{sid}/offline` 的 `available_run`，通过 `/api/sessions/{sid}/preview?run={run}` 下载固定完成版本。新版本下载解析期间保留原模型；切换会话后丢弃旧请求结果；精修状态临时失败时保留已显示精修版。接口仍要求配对 token。新会话先使用实时预览，首版精修完成后自动切换，之后按完成版本更新。

## 已实施的第一轮优化

- `pc/keyframes.py`：保留清晰度前 65% 照片，并按相对扫描原点的 12 个方位、3 个高度区间，补回每个已观测方向中最清晰的照片。方向覆盖是粗粒度代理指标，不是表面可见性证明。
- `publish_preview`：合并 UV 接缝产生的几何重复顶点，再做约 12000 面简化，移除未引用顶点。只影响轻量彩色预览，完整纹理 GLB 保持原样。
- 用户扫描 `bcae2024cbde4c5a` 实跑：纹理照片从 42 增至 45，补回 3 个方向；最终连通分量 80 → 63、三角面 14691 → 22145、处理时间约 49 → 64 秒。尚无独立几何真值；分量减少不能单独证明精度提升。同视角图中部分侧面缺口减少，顶部文字清晰度接近。
- 对同一份旧完整 GLB 进行回传构建的隔离比较：41382 顶点 / 12000 面 / 1729216 字节 → 6563 顶点 / 11999 面 / 622938 字节，体积减少约 64%。检查了面索引有效性。
- 9 项测试通过，包括方向稀缺视角保留、固定版本回传和 RGB-D 原流程。新结果发布为 `coverage-experiment-20261114`，实际下载 HTTP 200，624431 字节。
- 此轮尚未实现全局位姿优化、非刚性照片对齐，也未证实头显实机帧率改善。USB 可识别为序列号 `2G0YC1ZG3R015G` 的 Meta 设备，但 ADB 和 Meta 官方工具均无法枚举调试设备，APK 安装待恢复连接。

## 照片贴图回传修正

逐面颜色预览无法显示三角形内部的照片细节，这是 Quest 预览模糊的独立来源。新增 `preview?run={run}&textured=true`，传输保留 UV 接缝的完整精修网格及 JPEG 纹理（原始尺寸，上限 4096，不放大）。Quest 使用 UV 采样的无光照贴图材质；尚无精修版本时继续实时颜色网格。旧接口保留以兼容 PC 页面。

真实扫描 `coverage-experiment-20261114` 返回 66435 顶点、22145 面和 1024×1024 JPEG（117462 字节）。这是已验证的网络载荷，不能代替头显显示验证。9 项测试通过，包含纹理解码与 UV 数量检查。新的 APK 编译成功，待设备重新连接安装。

用户当前扫描 `8f0ec998c97d44f5` 在检查时仅有 20 个接受帧，尚未达到 24 帧自动精修门槛，状态仍为 scanning，不能将其粗模称为精修结果。
